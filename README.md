# TurtleBot3 Lab Setup

A quick setup repository for running TurtleBot3 Burger in Gazebo using ROS 1
Noetic or ROS 2 Humble/Jazzy.

## Supported systems

| Ubuntu | ROS | Simulator |
|---|---|---|
| 20.04 | Noetic | Gazebo Classic |
| 22.04 | Humble | Gazebo Classic |
| 24.04 | Jazzy | Gazebo Harmonic |

ROS must already be installed.

```bash
git clone https://github.com/YOUR_USERNAME/turtlebot3-lab-setup.git
